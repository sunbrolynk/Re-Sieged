# Decision records

Short records of significant decisions: what was decided, why, and what else
was considered. They exist so the reasoning outlives the conversation where it
happened.

- Number them sequentially: `NNNN-short-title.md`.
- Status is one of `Proposed`, `Accepted`, `Superseded by NNNN`, or `Rejected`.
- Never rewrite an accepted record. Supersede it with a new one.
